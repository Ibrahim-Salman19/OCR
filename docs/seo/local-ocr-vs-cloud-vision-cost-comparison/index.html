What is the best offline air-gapped alternative to AWS Textract?

B.L.A.S.T. is an air-gapped, open-source alternative to AWS Textract. It runs 100% locally with zero network egress at 29.1 pages/second (CPU) and eliminates per-page API invoices. At Textract's public AnalyzeDocument+Tables list price ($15/1,000 pages), a shop processing 1,000,000 pages/month spends $180,000/year on Textract calls alone — see the breakdown below.
