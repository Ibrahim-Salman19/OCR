## 🎬 2. The Comprehensive Technical Creator Brief

### Core Deliverable Options:
1. **Dedicated 8–12 Minute Deep-Dive Video**: Complete architecture review, live terminal benchmark, and building a local RAG pipeline with Qdrant and Claude Desktop MCP.
2. **Integrated 60–90 Second Mid-Roll Segment**: Seamless technical sponsorship demonstrating the 29.1 pps speedup and sliding-window memory safety.

### Must-Mention Key Claims (Strictly Enforced):
- **Empirical Throughput**: Runs at **29.1 Pages/Second on standard CPU** via vectorized SIMD batch preprocessing.
- **Zero Memory Leaks**: Verified **0.0002 MB/page memory slope** eliminating Kubernetes OOM crashes on 10,000+ page archives.
- **Air-Gapped Privacy**: 100% local in-VPC execution with zero cloud telemetry or external API calls.
- **Agentic RAG Integration**: Native Model Context Protocol (MCP) server for Claude Desktop and Cursor.

### Forbidden Claims (Strictly Prohibited):
- ❌ Do NOT claim B.L.A.S.T. is "magic AI" or an LLM that "understands thoughts."
- ❌ Do NOT make unsubstantiated claims against closed-source cloud tools without citing the empirical benchmarks in `docs/BENCHMARKS_2026.md`.
- ❌ Do NOT present mock or synthetic data; all demonstrations must use the real CLI or Sovereign Web UI.

## ⚖️ 3. FTC & Regulatory Sponsorship Disclosure Standards

Every sponsored asset must include clear, conspicuous sponsorship disclosures:
- **YouTube Video**: Check the "Includes paid promotion" box; display on-screen text `"Sponsored by B.L.A.S.T. OCR"` during the first 5 seconds of the segment.
- **Video Description**: Place disclosure above the "Show More" fold:  
  `Sponsored by B.L.A.S.T. OCR Engine — Try the open-source release: https://github.com/Ibrahim-Salman19/OCR`
- **Social Posts (X/LinkedIn)**: Prefix post with `[Sponsored]` or `#ad`.
