## 🖥️ 3. Sovereign Streamlit Web UI First-Run Architecture

When opening `http://localhost:8501` for the first time, users encounter an intuitive, guided interface:

1. **System Telemetry HUD**: Real-time badges display ONNX runtime provider (`CPUExecutionProvider` / `CUDAExecutionProvider`), memory buffer mode, and worker queue status.
2. **1-Click Demo Document Button**: `[⚡ LOAD DEMO FINANCIAL REPORT (3 PAGES)]` pre-loads a complex financial scan, eliminating the need to search local folders for sample files.
3. **Interactive Geometry Inspector**: Automatically reveals Tab 2 upon execution, rendering interactive SVG bounding boxes with confidence scores.
4. **Instant Multi-Format Downloads**: One-click download buttons for Markdown, DOCX, TXT, EPUB, and Searchable PDF.
